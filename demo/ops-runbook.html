5xx 급증
증상
  • API 5xx 응답률이 5분간 2% 초과
  • 로드밸런서 헬스체크 실패 급증
대응 절차
  • 로그 검색에서 status≥500, 최근 15분 필터링
  • DB 커넥션 풀·외부 API 상태 확인
  • 필요 시 이전 안정 배포로 롤백
  • 온콜 채널에 상황 공유 및 감사 로그 기록
AI fallback 상승
증상
  • Gemini API 429/5xx로 fallback 응답 비율 10% 초과
  • 페르소나 응답 지연 시간 증가
대응 절차
  • AI Key 관리에서 쿼터 잔량 확인
  • 보조 API 키로 라운드로빈 전환
  • fallback 응답 템플릿 정상 노출 여부 점검
  • 지속 시 기능 플래그로 해당 페르소나 일시 비활성화
큐 적체

  • 메시지 처리 지연 알람 발생
대응 절차
  • 워커 프로세스 수 확인 및 스케일 아웃
  • 실패 재시도 루프 여부 로그로 확인
  • 불필요한 저우선순위 작업 일시 중단
  • 적체 해소 후 큐 길이 추이 15분 모니터링
디바이스 침묵
증상
  • 다수 디바이스에서 30분 이상 하트비트 미수신

  • 최근 OTA 배포 이력과 상관관계 점검

배터리 저전압
증상
  • 디바이스군 배터리 잔량 15% 미만 비율 급증
  • 비정상 방전 패턴(단시간 급락) 리포트 발생
대응 절차
