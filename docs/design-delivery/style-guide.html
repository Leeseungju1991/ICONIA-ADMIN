ICONIA Admin — 스타일 가이드

app/globals.css의 전역 유틸리티 클래스와 app/dashboard/_components/의 실제 컴포넌트를 기준으로 만든 정적 스타일 가이드입니다. 빌드 없이 브라우저로 바로 확인할 수 있고, 핵심 기능(표·폼·카드·모달)뿐 아니라 부기능(토글·탭·아코디언·배지·인쇄)까지 웹앱이 실제로 쓰는 스타일을 전부 담았습니다. 전체 사이트맵/페이지 목록은 README.md 참고.

14. 기타 규칙

부기능
모션 감소 대응

prefers-reduced-motion: reduce 시 스피너 회전과 신규 행 fade 애니메이션을 모두 끈다.

인쇄 스타일
