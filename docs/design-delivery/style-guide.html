ICONIA Admin — 스타일 가이드 (20종)

app/globals.css 전역 유틸리티(.btn-*/.input/.chip-*/.glass-*)와 app/dashboard/_components/의 실제 컴포넌트를 기준으로 하고, 아직 앱에 없지만 일반적인 웹앱에서 널리 쓰이는 패턴(툴팁·드롭다운·스켈레톤·스텝퍼 등)을 더해 20개 카테고리로 정리했습니다. 섹션 헤더의 적용중은 현재 코드에 있는 패턴, 제안은 이 문서에서 새로 제안하는 일반 패턴입니다. 대부분 실제로 클릭 가능한 동작 데모입니다 — 프레임워크 없이 바닐라 JS ~120줄로 구현.
