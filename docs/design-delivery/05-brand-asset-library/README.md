# 마케팅 콘텐츠·브랜드 에셋 라이브러리

브랜드 에셋을 다루는 3가지 서로 다른 방향성입니다(A/B/C). 각 시안은 진입 페이지(아래 링크)에서
시작해 실제로 여러 세부 화면을 오가며 동작합니다 — 다운로드 수·즐겨찾기·업로드 목록은
브라우저에 실제로 저장되어(localStorage) 새로고침해도 유지됩니다.

| 시안 | 미리보기 | 방향성 | 세부 페이지 |

| [A](./variant-a.html) | ![A](./preview-a.svg) | **썸네일 그리드·태그 필터형** — 사진·디자인 자산 탐색의 표준 패턴 | 홈(검색·유형 필터 실동작) → [에셋상세](./variant-a-detail.html)(다운로드 수 실제 누적) |
