# 기능 · 컴포넌트 (부품 목록)

5개 주제 폴더(01~05)가 공통으로 재사용하는 **부품 목록**입니다. 여기서 먼저 어떤 부품이
있는지 확인한 뒤, 주제 폴더에서 그 부품들을 실제로 조립한 화면을 보는 순서를 권장합니다.

## 이 폴더의 파일

| 파일 | 역할 |
|---|---|
| [`style-guide.html`](./style-guide.html) | **20개 카테고리 + 완성 페이지 예시(P1~P5) 인터랙티브 카탈로그.** 버튼·폼·카드·표·모달·스낵바 등 모든 부품을 직접 클릭해볼 수 있는 단일 페이지. 다크모드 토글 포함. |
| [`tokens.css`](./tokens.css) | 01~05 주제 폴더의 모든 시안이 공유하는 디자인 토큰 + 베이스 컴포넌트 스타일시트 |
| [`interactions.js`](./interactions.js) | 01~05 주제 폴더가 공유하는 바닐라 JS 인터랙션 헬퍼 (토글·탭·드롭다운·모달·스낵바 등) |

## 미리보기

`style-guide.html`은 이미지 미리보기 대신, 링크를 열면 그 자체로 20개 부품을 직접 눌러볼 수
있는 카탈로그입니다 — [바로 열기](./style-guide.html).

## 왜 별도 폴더인가

01~05 폴더의 시안들은 새 컴포넌트를 만들지 않고 이 폴더의 `tokens.css`/`interactions.js`만
`<link>`/`<script src>`로 참조합니다. 부품을 여기 한 곳에서만 정의해두면:
- 색상 토큰이나 버튼 스타일을 바꿀 때 이 폴더 파일 2개만 고치면 5개 주제 폴더 전부에 반영됩니다.
- 다크모드 선택이 `localStorage`로 공유되어, 한 시안에서 다크모드를 켜면 다른 시안을 열어도 유지됩니다.
