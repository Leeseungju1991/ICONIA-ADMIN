# 부품 20종

10개 대주제 폴더가 공통으로 재사용하는 부품 목록입니다. 여기를 먼저 보면 주제 폴더의 화면이
어떤 조각으로 조립됐는지 바로 이해가 됩니다.

| 파일 | 역할 |
|---|---|
| [`style-guide.html`](./style-guide.html) | **20개 카테고리 인터랙티브 카탈로그** — 컬러·타이포·버튼·폼·체크토글·배지·카드·탭·아코디언·브레드크럼·드롭다운·툴팁·내비게이션·배너·스낵바·모달·표·스켈레톤·진행바·상태유틸. 클릭해서 직접 동작을 확인할 수 있고, 다크모드 토글 포함. |
| [`theme-generator.html`](./theme-generator.html) | **실시간 테마·화면 구성 생성기** — 색상 팔레트(프리셋 6종 + 직접 HEX 선택), 대주제 화면, 소주제 화면(구성 프리셋), UI/UX 구성요소(KPI 카드·표·칸반·채팅·체크리스트·폼·탭·배너)를 좌측에서 고르면 우측에 즉시 조합되어 보이고, 확정한 색상 값을 코드로 바로 복사할 수 있음. |
| [`tokens.css`](./tokens.css) | 대주제 10개가 공유하는 디자인 토큰(색상·그림자·라운드) + 베이스 컴포넌트 스타일 |
| [`interactions.js`](./interactions.js) | 대주제 10개가 공유하는 바닐라 JS 인터랙션 헬퍼 (토글·탭·드롭다운·모달·스낵바·칸반·체크리스트 등) |
| [`ICONIA-ADMIN-CONSOLE.md`](./ICONIA-ADMIN-CONSOLE.md) | (참고 자료) 실제 ICONIA 운영 콘솔 앱의 UI/UX 전달 문서 — 이 부품 20종이 어떤 실제 앱 화면·코드에서 나왔는지의 근거 |

**바로 열기**: [`style-guide.html`](./style-guide.html)

대주제 폴더들은 새 컴포넌트를 따로 만들지 않고 `tokens.css`/`interactions.js`만
`<link>`/`<script src>`로 참조합니다. 토큰이나 버튼 스타일을 바꿀 때 이 폴더 파일 2개만
고치면 10개 대주제 전부에 반영되고, 다크모드 선택도 `localStorage`로 공유되어 한 시안에서
켜면 다른 시안에서도 유지됩니다.
