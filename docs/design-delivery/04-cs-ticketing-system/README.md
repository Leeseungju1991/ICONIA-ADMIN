# 고객 문의(CS) 티켓팅·응대 관리 시스템

CS 문의를 다루는 3가지 서로 다른 방향성입니다(A/B/C). 각 시안은 진입 페이지(아래 링크)에서
시작해 실제로 여러 세부 화면을 오가며 동작합니다 — 답변·담당자 배정·채팅 메시지는
브라우저에 실제로 저장되어(localStorage) 새로고침해도 유지됩니다.

| 시안 | 미리보기 | 방향성 | 세부 페이지 |
|---|---|---|---|
| [A](./variant-a.html) | ![A](./preview-a.svg) | **목록+상세 분할형(상담사용)** — 이메일 클라이언트 패턴, 하루종일 여러 티켓을 넘기며 처리 | 홈(목록+상세, 답변발송 시 상태 실제 변경) → [고객 히스토리](./variant-a-customer.html) |
| [B](./variant-b.html) | ![B](./preview-b.svg) | **칸반 보드형(팀장·매니저용)** — 처리 단계별 전체 현황 관리 | 홈(카드 이동 실제 저장) → [티켓상세](./variant-b-detail.html)(담당자·우선순위 지정) → [새 티켓 등록](./variant-b-new.html) |
| [C](./variant-c.html) | ![C](./preview-c.svg) | **대화형 채팅 스레드(라이브챗)** — 실시간 채팅 상담에 자연스러운 형태 | 대화 목록 → [채팅상세](./variant-c-chat.html)(메시지 전송·내부 메모 실동작) |
| [D](./variant-d.html) | ![D](./preview-d.svg) | SLA 임박 순 — 남은 시간 카운트다운 칩으로 정렬(단일 화면 목업) |
