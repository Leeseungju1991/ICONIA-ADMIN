# 사내 통합 임직원 서비스 포털

임직원 셀프서비스를 다루는 3가지 서로 다른 방향성입니다(A/B/C). 각 시안은 진입 페이지(아래 링크)에서
시작해 실제로 여러 세부 화면을 오가며 동작합니다 — 서비스 신청·신청 취소·연차 차감은 브라우저에
실제로 저장되어(localStorage) 새로고침해도 유지됩니다.

| 시안 | 미리보기 | 방향성 | 세부 페이지 |
|---|---|---|---|
| [A](./variant-a.html) | ![A](./preview-a.svg) | **서비스 타일 그리드형(전 직원 진입점)** — 아이콘 타일로 "어디서 뭘 신청하는지" 직관적으로 | 홈(타일) → [서비스신청](./variant-a-detail.html)(신청 실제 저장) |
| [B](./variant-b.html) | ![B](./preview-b.svg) | **신청 내역 표·모달형(추적형)** — 내 신청이 어떻게 됐는지 추적 | 홈(표+새신청 모달, 실제 추가 저장) → [신청상세](./variant-b-detail.html)(신청 취소 실제 저장) |
| [C](./variant-c.html) | ![C](./preview-c.svg) | **개인화 대시보드형** — "나"를 중심에 둔 매일 로그인 화면 | 홈(내 정보+빠른신청) → [연차신청](./variant-c-leave.html)(신청 시 잔여 연차 실제 차감) |
| [D](./variant-d.html) | ![D](./preview-d.svg) | 담당자 찾기 — 검색 + 조직도형 카드 리스트(단일 화면 목업) |
